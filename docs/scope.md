# Project scope

Understand ReSTIR through selected reproductions and comparisons, then use observed limitations to identify questions for future research.

## Core work

- Use RTXDI and selected Falcor implementations, with fixed code versions.
- Reproduce ReSTIR DI and choose GI or PT as the second study.
- Evaluate methods on public scenes, adding controlled scenes when needed.
- Document results, failure cases, and implementation differences with reproducible configurations.

## Deliverables

- Source code, scene configurations, and experiment records.
- Literature review and analysis of the reproduced methods.
- Course proposal, report, and demonstration, including implementation provenance.

## Optional extensions

Reproduce another method or explore an improvement if the core work is complete and time permits.

Track milestones in [the roadmap](roadmap.md) and record method, renderer, and scene choices in [decisions](decisions/).
