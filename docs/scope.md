# Project scope

The project evaluates ordinary spatial reuse, PDF Similarity and CGNS. The RTXDI work starts with direct lighting. The final comparison evaluates the three methods in Falcor ReSTIR PT at matched sampling settings, using six fixed views and matched reference images. An interactive Falcor demo exposes the two adapted methods and three display modes.
