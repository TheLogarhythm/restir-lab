# ReSTIR literature

The project compares two spatial-reuse decisions. PDF Similarity adjusts the influence of a proposed donor using a directional distribution. CGNS uses geometric compatibility to select a donor before path shifting. The original DI and GRIS papers define the estimators that these adaptations extend.

| Work | Relevance to this project |
| --- | --- |
| [Bitterli et al. 2020](https://doi.org/10.1145/3386569.3392481) | Introduces spatial and temporal reservoir reuse for direct illumination. |
| [Lin et al. 2022](https://doi.org/10.1145/3528223.3530158) | Generalizes RIS to correlated samples, different domains and shift mappings in ReSTIR PT. |
| [Tokuyoshi 2023](https://doi.org/10.1145/3585501) | Uses PDF similarity for spatial resampling. The project's PT adaptation summarizes the first path segment. |
| [Junkins et al. 2026](https://doi.org/10.1145/3820024) | Uses a geometric compatibility score to select neighbors and evaluates image error, covariance and cost. |

For the broader literature, including work on camera integration, visibility and alternative transport estimators, use the [ReSTIR Atlas data guide](restir-map/README.md) and [reading matrix](reading-matrix.csv). [Project method guides](../reproductions/README.md)
