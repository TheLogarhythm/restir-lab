# Optional original trajectory videos

This is the companion archive for restir-final-handoff. It contains twelve original encoded method MP4s plus retained timing, camera/capture and encode records. Each video is1080p,30FPS,300frames,10seconds. Main-package slides already include four synchronized three-method comparison videos and need no files from this optional ZIP to play.

Preserve the runs/ and scenes/ relative paths when merging with the main bundle. Open runs/pt-4-trajectories-spatial-compare/index.html to browse. No original capture EXR/PNG sequences or diagnostic HDR are supplied. Original archive-manifest.json is provenance for the full compact archive; use this ZIP's checksums.sha256 for the delivered subset. Historical records may refer to files deliberately excluded here. Videos cannot reconstruct linear HDR or provide reference-based moving-view quality metrics.

Run python tools/verify_handoff.py to check snapshot hashes. FFmpeg is optional for independent decoding checks. No rendering is required.
