# Historical Bistro FBX importer

The Bistro FBX composition and glass-bypass scouts have been retired. The C++ source documents how the prototype imported a second FBX with a measured scale and translation, using Falcor's Assimp importer for materials and textures. The archived scout manifests still describe the original layout.

Current experiments use the glTF Bistro interior and ORCA exterior. Their inputs, supported runtimes and conversion steps are listed in the [six-scene preparation guide](../../../experiments/configs/falcor-pt-spatial-comparison/PREPARATION.md).
